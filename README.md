# Momentum Focus | Premium Study Timer

An aesthetic, minimalist Pomodoro timer and focus tracker designed specifically for JEE aspirants and deep work sessions. 

### 🚀 Live Demo
**[Try the app here!](https://momentumbyansh.netlify.app)**

### ✨ Features
* **Zero Distractions:** Clean, glassmorphism UI.
* **Progressive Web App:** Fully installable on desktop and mobile.
* **Local Analytics:** Predictive focus engine that tracks your 7-day momentum and highlights your best study days.
* **Custom Themes:** Multiple color palettes including Zen Matcha, Dark Cocoa, and Science Blueprint.
* **Built-in Audio:** Custom synthesized alarm tones using the Web Audio API.

### 🛠️ Built With
* HTML5
* CSS3 (Vanilla)
* JavaScript (Vanilla)
* Local Storage API
* Web Audio API
